## 도서 기획

### 핵심 메시지 (Big Idea)

> 공공 영역에 AI 기반 의사결정 시스템을 도입할 때, **무엇을 설계하고 무엇을 검증해야 하는가?** — 이론은 구현될 때 비로소 검증된다.

### 독자 페르소나

- 공공기관 AI 도입 담당자
- 정책연구자, 대학원생
- AI 거버넌스·공공 데이터 분석 실무자

### 전체 목차

4부 12장 구성 — 상세 목차는 `contents.md` 참조

### 서술 원칙
1. 이론은 구현될 때 비로소 검증된다 — 각 장마다 진단 항목·체크리스트·평가 기준을 구체적으로 도출
2. 기존 저서와의 차별 — 분석 기법이 아니라 **설계와 검증의 구조**에 집중
3. 한국 맥락의 구체성 — 국내 법·제도·사례 중심, 국제 기준(EU AI Act, OECD, NIST) 비교 병행

## 저자 자산 (기존 출판물)

- **인과 데이터 사이언스** (2026, 법문사) — PSM, DID, RDD, IV, Deep PSM, Causal Forest
- **Python AI 기반 데이터사이언스 방법론** (2026, 윤성사) — ML/DL 전 과정, BERTopic, VAE, TimeGPT
- **LLM 시대의 인문사회과학방법론** (2025, 윤성사) — Transformer, RAG, 멀티에이전트, 16장
- **구조방정식모형의 이해와 R분석** (2021, 윤성사) — SEM, 잠재성장모형
- **빅데이터 분석방법론** (2019, 윤성사, 세종도서) — 텍스트마이닝, NLP, word2vec
- **R과 STATA 평가방법론** (2018, 법문사) — 준실험설계, 영향평가

## 집필 순서 (역순 전략)

Phase 1~3에서 제2부(4~6장)를 먼저 집필 → Phase 2에서 제3부(7~9장) → Phase 3에서 제4부(10~12장) → 마지막에 제1부(1~3장) 최종 보강.
이유: 제1~3장은 칼럼 기반 초안이 있으므로, 실무(검증 도구)가 이론(프레임워크)을 검증하는 SAPD 원리를 집필 과정에도 적용.

## 작업 원칙

- **문제 회피 금지**: 문제가 발생할 경우 피해가지 말고, 항상 해결 방법을 생각하고 실행한다.
- **챕터 저장 원칙**: 집필 완료된 챕터는 반드시 최상위 `chapter/` 폴더에 저장한다.
- **MVP 동기화**: 집필은 sapd/dev/ MVP 개발과 병행. 각 장의 진단 항목이 프로토타입 기능의 설계 근거가 된다.
