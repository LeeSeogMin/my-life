# Phase 1 Command: 기획 & 목차

## 역할
도서 컨셉을 구체화하고, 독자 분석·경쟁 도서 조사를 통해 목차 v1과 집필 로드맵을 확정한다.

## 사전 조건
- `CLAUDE.md`에 도서 제목 및 핵심 주제 기재
- `contents.md` (4부 12장 장별 계획) 확인
- `context.md`, `todo.md` 확인

## 특수 사항 (SAPD 도서)
- contents.md에 이미 4부 12장 구조와 장별 상세 계획이 존재
- Phase 1은 이 계획을 검증·보완하고, 경쟁 도서 분석과 독자 페르소나를 추가하는 것이 핵심
- 칼럼 2편(제1~3장 초안)과 저서 6권(방법론 중복 방지)을 반드시 참조

## 실행 프로세스

### Step 1: 핵심 가치 명제 검증
- contents.md의 Big Idea를 독자 관점에서 1문장으로 재정리
- 도서 포지셔닝 확정: 전문교양서 (학술서와 실용서 사이)

### Step 2: 독자 페르소나 분석
- 최소 3개의 독자 페르소나 작성
- 각 페르소나: 직업, 연령대, 현재 고민, 이 책에서 기대하는 것
- 주 독자층(Primary)과 부 독자층(Secondary) 구분

### Step 3: 경쟁 도서 분석
- 국내외 경쟁·참조 도서 10~15권 조사
- 분야: 공공 AI 거버넌스, 정책분석 방법론, XAI/설명가능성, AI 윤리/공정성
- `data-patterns.md` 경쟁 도서 분석 템플릿 사용

### Step 4: 목차 v1 확정
- contents.md 기반으로 세부 조정
- 분량 배분 계획 (전체 목표 분량 기준 챕터별 예상 매수)
- 챕터 간 논리적 흐름 최종 확인

### Step 5: 집필 로드맵 작성
- 역순 전략 확정: 제4장(오류 유형) → 제5장(XAI) → 제6장(타당성) 순
- Phase 3 집필 시작 전 완료 사항 정의
- 수집 필요 자료 우선순위 목록 작성 (→ Phase 2 입력)

### Step 6: 산출물
`book1_planning/` 에 저장:
- `big_idea.md` — 핵심 가치 명제 및 포지셔닝
- `reader_personas.md` — 독자 페르소나 3개 이상
- `competitive_analysis.md` — 경쟁 도서 분석표
- `table_of_contents_v1.md` — 목차 v1 (contents.md 기반 확정)
- `writing_roadmap.md` — 집필 로드맵
