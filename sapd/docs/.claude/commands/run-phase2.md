# Phase 2 Command: 조사 & 근거

## 역할
목차 v1 기반으로 챕터별 근거 자료를 체계적으로 수집한다. 사례 카드, 통계 은행, 챕터-자료 매핑표를 구축하여 Phase 3 집필 기반을 마련한다.

## 사전 조건
- Phase 1 완료 (`book1_planning/table_of_contents_v1.md` 존재)

## 특수 사항 (SAPD 도서)
- 제1~3장: 칼럼 2편 기반 — 추가 조사는 보충 수준
- 제4~6장(Phase 1 집필 대상): 최우선 자료 수집 — 국내외 AI 오류 사례, XAI 기준, 정책분석 타당성 사례
- 제7~9장: Validation Module 관련 — 공정성 사례, 루브릭 사례, 기존 체크리스트 수집
- 제10~12장: 새로 학습 영역 — EU AI Act, 한국 AI 기본법, 공공조달 절차 등 제도 자료 수집

## 실행 프로세스

### Step 1: 수집 계획 수립
- 목차 v1 기반으로 챕터별 필요 자료 유형 정의
- 수집 소스: 학술 논문, 정부 보고서, 국제기구 문서(OECD, EU, NIST), 국내 법령, 사례

### Step 1.5: 원본 자료 다운로드
- 웹 검색(WebSearch)으로 필요 자료 탐색
- WebFetch로 PDF·문서를 직접 다운로드하여 `book2_research/` 하위 폴더에 저장
  - `papers/` — 학술 논문
  - `reports/` — 정부·국제기구 보고서
  - `laws/` — 법령·가이드라인 원문
  - `datasets/` — 통계 원데이터
- 다운로드한 모든 자료를 `references_index.md`에 색인 기록

### Step 2: 사례 카드 수집 (30개 이상)
- `data-patterns.md` 사례 카드 표준 형식 적용
- 중점 영역: 공공 AI 실패 사례, 편향 사례, XAI 적용 사례, 국회 회의록 분석 사례
- 각 카드: 사례명, 출처, 핵심 수치, 배경, 시사점, 배치 챕터

### Step 3: 통계 은행 구축
- 챕터별 핵심 통계 수치 수집 및 검증
- `data-patterns.md` 통계 수치 검증 체크리스트 적용

### Step 4: 시각화 자료 준비
- SAPD 5대 레이어 아키텍처 다이어그램
- 순환 피드백 루프 다이어그램
- Validation Module 3차원 검증 공간 도표
- 오류 유형 분류표, XAI 진단 매트릭스 등

### Step 5: 챕터-자료 매핑
- `data-patterns.md` 챕터별 자료 매핑표 작성
- 자료 충분도 점검: 챕터당 사례 2개 이상, 통계 3개 이상 권장

### Step 6: 산출물
`book2_research/` 에 저장:
- `cases/case_card_XXX.md` — 사례 카드 (30개 이상)
- `statistics_bank.md` — 통계 은행
- `figures/ch[N]_fig[N]_*.png` — 시각화 자료
- `chapter_resource_map.md` — 챕터-자료 매핑표
