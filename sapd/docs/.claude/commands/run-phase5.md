# Phase 5 Command: 다중 LLM 리뷰

## 역할
Claude, GPT-4, Gemini를 활용해 도서 원고를 반복 검토하고 수정한다. **도서 기준 타당성 필터**를 적용하여 학술 논문식 피드백은 걸러낸다.

## 사전 조건
- Phase 4 완료 (`chapter/` 폴더에 최종 편집 버전 존재)

## ⚠️ 도서 기준 타당성 필터
다음 피드백은 도서에 적합하지 않으므로 **반드시 거부**한다:
- "더 학술적인 표현을 써라"
- "인용 문헌을 더 달아라"
- "챕터를 논문처럼 재구성해라"
- "통계적 유의성 검증을 추가해라"
- "방법론 섹션을 추가해라"

## 특수 사항 (SAPD 도서)
- **학술적 정확성은 유지하되 도서 문체로**: SAPD 이론의 학술적 엄밀성은 보존하면서 전문교양체 유지
- **실무 산출물 리뷰**: 각 장의 체크리스트·매트릭스가 실제 현장에서 사용 가능한지 검증
- **한국 맥락 검증**: 국내 법·제도 인용의 정확성 확인

## 실행 프로세스

### Step 1: 리뷰 실행 (3개 LLM)

**Claude** (논리 일관성)
- 주장-근거-사례 연결의 논리적 흐름
- SAPD 프레임워크와 각 장 내용의 정합성
- 챕터 간 논증 일관성

**GPT-4** (독자 경험)
- 도입부의 독자 흡인력
- 어려운 개념 설명의 명확성
- 실무 산출물의 실용성

**Gemini** (자료 완성도 & 사실 확인)
- 사례·통계 수치의 정확성
- 법·제도 인용의 최신성
- 국제 기준(EU AI Act, OECD 등) 정확성

### Step 2: 리뷰 종합
- 피드백을 타당성 필터로 1차 걸러내기
- 통과한 피드백을 Major/Minor로 분류
- 3개 LLM에서 공통으로 지적한 사항 우선 처리

### Step 3: 수정 반영
- Major 이슈부터 순차 처리
- `chapter/chapter_[N].md` 업데이트
- 수정 내역 `book5_review/revision_history.md`에 기록

### Step 4: 반복 (최대 5회)
- 모든 LLM에서 Minor 이하만 남을 때까지 반복

### Step 5: 산출물
`book5_review/` 에 저장:
- `reviews/round_[N]_claude.md`, `round_[N]_gpt4.md`, `round_[N]_gemini.md`
- `revision_history.md` — 수정 이력
