# Phase 3 Command: 챕터 집필

## 역할
목차 v1과 수집된 자료를 바탕으로 각 챕터를 집필한다. 집필 완료 챕터는 반드시 최상위 `chapter/` 폴더에 저장한다.

## 사전 조건
- Phase 2 완료 (`book2_research/chapter_resource_map.md` 존재)
- `book1_planning/table_of_contents_v1.md` 확인

## ⚠️ 핵심 규칙
**집필 완료 챕터는 반드시 `chapter/chapter_XX.md`에 저장한다.**
`book3_drafting/` 은 브리프, 노트, 진행 현황 등 중간 산출물 전용.

## 특수 사항 (SAPD 도서)
- **역순 집필**: 제4장 → 제5장 → 제6장 → 제7장 → 제8장 → 제9장 → 제10장 → 제11장 → 제12장 → 제1장 → 제2장 → 제3장
- **제1~3장**: 칼럼 기반 확장 — 마지막에 집필. 제4~12장 완성 후 이론부를 보강
- **각 장의 실무 산출물**: 진단 항목, 체크리스트, 평가 기준을 본문 안에 포함 (contents.md 참조)
- **문체**: 학술적 전문교양체 — 저자의 기존 칼럼 문체 참조. 논문체가 아닌 도서체

## 실행 프로세스

### Step 1: 챕터 브리프 작성
- 대상 챕터 번호 및 제목 확인
- `book3_drafting/brief_ch[N].md` 작성:
  - 이 챕터에서 독자가 얻는 핵심 통찰 1문장
  - 사용할 사례 카드 목록
  - 활용할 통계·시각화 자료
  - 오프닝 훅 유형 (사례형/질문형/통계형)
  - **실무 산출물** 명세 (체크리스트/매트릭스/템플릿)

### Step 2: 오프닝 훅 작성
- `writing-patterns.md` 패턴 1(챕터 오프닝 훅) 적용
- 독자를 즉시 끌어들이는 도입부 (200~400자)

### Step 3: 본문 집필 (PIER 구조)
- `writing-patterns.md` 패턴 2(PIER 논증 구조) 적용
- 전문교양체 문체 유지 (패턴 3)
- 박스·콜아웃 적절히 활용 (패턴 4)
- 피해야 할 표현 점검 (패턴 9)

### Step 4: 클로징 작성
- `writing-patterns.md` 패턴 5(챕터 클로징 구조) 적용
- 핵심 요약 + 다음 챕터 연결

### Step 5: 시각화 자료 통합
- 본문 내 그림/표 삽입 위치 확정
- `writing-patterns.md` 패턴 6(그림/표 캡션) 적용

### Step 6: 산출물 저장
**최신 챕터 버전:**
- `chapter/chapter_[NN].md` ← **반드시 이 경로에 저장**

**중간 산출물:**
- `book3_drafting/brief_ch[N].md` — 챕터 브리프
- `book3_drafting/draft_progress.md` — 전체 집필 진행 현황 업데이트

## 완료 기준

- [ ] 전문교양체 문체 및 PIER 구조 준수
