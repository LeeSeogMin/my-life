# Phase 7 Command: 한국어 교정

## 역할
국립국어원 어문 규범을 기준으로 원고 전체를 5단계 전문 교정한다. 맞춤법·띄어쓰기부터 가독성까지 체계적으로 점검하여 출판 가능 수준의 원고를 완성한다.

## 사전 조건
- Phase 6 완료 (`chapter/` 폴더에 humanized 버전 존재)

## 실행 프로세스

### Step 1: 맞춤법 & 띄어쓰기 교정
- 국립국어원 어문 규범 기준
- 한글 맞춤법, 외래어 표기법, 로마자 표기법 적용
- 의존 명사 띄어쓰기 일관성

### Step 2: 문체 일관성 확인
- 전문교양체 어조가 전체에 걸쳐 유지되는지 점검
- 서술어 어미 일관성 (했다/한다 혼재 등)

### Step 3: 용어 통일
- `book4_editing/glossary.md` 기준으로 용어 표기 통일
- SAPD 고유 용어 표기 일관성 최종 확인
- 영어 원어·한글 번역어 병기 규칙 적용

### Step 4: 가독성 점검
- 지나치게 긴 문장 분리 (1문장 60자 초과 시 검토)
- 단락 길이 적정성 확인 (500자 이상 단락 분리 검토)
- 반복 어구·접속사 과다 사용 수정

### Step 5: 최종 교열
- 오탈자 잔류 여부 최종 확인
- 구두점 사용 일관성
- 참고 출처 표기 형식 확인 (`writing-patterns.md` 패턴 7)
- 그림·표 캡션 형식 최종 확인 (패턴 6)

### Step 6: 산출물
`book7_editing/` 에 저장:
- `style_guide_kr.md` — 이 도서 적용 한국어 스타일 가이드
- `proofreading_checklist.md` — 교정 체크리스트 (항목별 결과)

`chapter/` 업데이트:
- 교정 완료 버전으로 전체 챕터 파일 업데이트
