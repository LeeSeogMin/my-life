# Paper Review Skill - 다중 LLM 리뷰 프레임워크

## 목적
Phase 5에서 다중 LLM을 활용한 원고 리뷰를 수행합니다.

## 리뷰어 구성

### Claude
**전문 영역**: 논리 일관성, SAPD 프레임워크 정합성

**체크 포인트**:
- [ ] 전체 목차와 내용이 일치하는가?
- [ ] 각 챕터의 핵심 주장이 SAPD 프레임워크와 정합적인가?
- [ ] 챕터 간 연결이 자연스러운가?
- [ ] 제9장(통합)이 제4~8장의 진단 항목을 실제로 통합하는가?

### GPT-4
**전문 영역**: 독자 경험, 가독성, 실무 산출물 실용성

**체크 포인트**:
- [ ] 비전문 독자가 이해할 수 있는가?
- [ ] 훅이 효과적인가?
- [ ] 실무 산출물(체크리스트)이 실제 현장에서 사용 가능한가?
- [ ] 행동 제안(Action Step)이 구체적인가?

### Gemini Pro
**전문 영역**: 자료 완성도, 사실 확인, 법·제도 정확성

**체크 포인트**:
- [ ] 통계 수치의 출처가 명확한가?
- [ ] EU AI Act, OECD 등 국제 기준 인용이 정확한가?
- [ ] 한국 법·제도 인용이 최신인가?
- [ ] 누락된 중요 사례나 연구가 없는가?

## 타당성 필터 (도서 기준)

### ✅ 타당한 리뷰 (수용)
- 특정 챕터/섹션/문장을 구체적으로 지목
- 독자 경험을 실제로 개선하는 피드백
- 실무 산출물의 실용성 개선 제안
- 용어 통일, 문체 일관성 지적

### ❌ 무효한 리뷰 (거부)
- "더 학술적으로 써라" → 도서는 전문교양체
- "인용을 더 달아라" → 도서는 선택적 인용으로 충분
- "챕터를 논문 형식으로 바꿔라" → 도서 구조 침해
- "더 객관적으로 써라" → 저자의 관점이 도서의 가치

## 완료 기준

다음 중 하나:
1. **모든 리뷰어 Accept**: 5개 기준 모두 4점 이상
2. **타당한 의견 모두 반영**: 무효 피드백 제외 후 전수 반영
3. **5회 반복 완료**: 최대 시도 횟수 초과

**출판 준비 기준**: 5개 기준 평균 4.0 이상
