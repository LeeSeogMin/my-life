## 2026-03-12: 초기화 - 역순 집필 전략

### 상황
제1~3장은 이미 칼럼 2편으로 초안이 존재. 제4장부터 시작하여 실무(검증 도구)가 이론(프레임워크)을 검증하는 구조.

### 해결책
역순 집필 전략 채택: 제4장 → ... → 제12장 → 제1~3장 최종 보강.

### 학습
- **규칙**: 초안이 있는 장은 마지막에 보강 — 다른 장의 결과물이 이론부를 강화
- 칼럼 기반 장은 도서 문체로 확장 시 분량·깊이가 크게 변하므로, 전체 윤곽이 잡힌 후 착수

## 2026-03-12: 초기화 - 기존 저서와의 중복 방지

### 상황
저자가 이미 6권의 방법론 교재를 출판. 인과추론, ML/DL, LLM 기법은 이미 다른 저서에서 상세히 다룸.

### 해결책
이 도서는 **방법론(how to analyze)이 아닌 설계와 검증(what to check)**에 집중. 분석 기법 자체가 아니라, 그 기법이 공공 의사결정에 투입될 때 충족해야 할 조건을 다룬다.

### 학습
- **규칙**: "이 내용은 다른 저서에 있는가?" 검토 후 중복 시 참조만 표기
- 기법 설명이 필요한 경우, 기존 저서를 참고문헌으로 안내하고 본문에서는 설계/검증 관점만 다룸
