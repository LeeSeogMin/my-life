# Writing Patterns - 한국어 전문도서 작문 패턴

> Phase 3(챕터 집필), Phase 4(구조 편집), Phase 7(한국어 교정)에서 재사용

---

## 패턴 1: 챕터 오프닝 구조 (훅)

### 사용 시점
각 챕터 첫 단락. 독자가 계속 읽고 싶게 만드는 것이 목적.

### 유형별 예시

**A. 사례형 훅** (구체적 사건으로 시작)
```
2020년 3월, 네덜란드 세무당국은 아동수당 부정수급 탐지 알고리즘이
수만 가구에 부당한 환수 결정을 내린 사실을 인정했다.
알고리즘은 '정확'했다. 문제는 정확성이 아니라 설계에 있었다.
```

**B. 질문형 훅** (독자의 고민을 직접 질문)
```
공공기관이 도입한 AI가 틀린 결론을 냈다면, 누가 책임져야 하는가?
개발자인가, 도입을 결정한 공무원인가, 아니면 AI 자체인가?
```

**C. 통계형 훅** (충격적 수치로 시작)
```
OECD 42개국 중 공공 AI 사전 검토 체계를 법제화한 나라는 아직 5개국에 불과하다.
나머지 37개국은 AI를 도입한 후에야 문제를 발견하고 있다.
```

### 피해야 할 오프닝
- "이 챕터에서는 ~에 대해 다룹니다" (안내 형식)
- "~은 매우 중요합니다" (당연한 말)
- "최근 들어 ~에 대한 관심이 높아지고 있습니다" (진부한 시작)

## 패턴 2: 본문 논증 구조 (PIER)

### 사용 시점
각 섹션의 핵심 주장 전개 시.

```
Point     (주장): 핵심 주장을 1~2문장으로 명확하게 제시
Illustration (근거): 통계, 연구, 전문가 의견으로 뒷받침
Example    (사례): 구체적인 기관/제도/사건 사례 1~2개
Relevance  (시사점): 독자에게 주는 의미, SAPD 프레임워크와의 연결
```

## 패턴 3: 전문교양체 문체 기준

### 타겟 수준
대학 교육 이상 독자가 이해 가능하면서도 학술적 전문성 유지.

### 적용 기준

| 항목 | 기준 |
|------|------|
| 문장 길이 | 1문장 30~50자 |
| 태 | 능동태 선호 |
| 주어 | 명확하게 |
| 비유 | 1챕터 1~2개 |
| 문장 구조 | 단문·복문·중문 혼용 (아래 규칙 참조) |

### 문장 구조 혼용 규칙 (필수)
단조로운 문장 반복을 방지하기 위해 **단문(短文)·복문(複文)·중문(重文)**을 의식적으로 혼용한다.

| 유형 | 특징 | 예시 |
|------|------|------|
| **단문** | 주어+서술어 1개, 짧고 명쾌 | "이 프레임워크는 5개 레이어로 구성된다." |
| **복문** | 종속절+주절, 인과·조건·양보 관계 표현 | "오류 유형을 분류하지 않으면, 검증 기준을 설계할 수 없다." |
| **중문** | 대등절 2개 이상, 병렬·대조 관계 표현 | "설명가능성은 기술적 요건이고, 책임성은 제도적 요건이다." |

**적용 원칙**:
- 핵심 주장은 **단문**으로 선명하게
- 근거·인과 관계는 **복문**으로 논리적으로
- 비교·대조는 **중문**으로 균형감 있게
- 같은 유형의 문장이 **3회 이상 연속**되지 않도록 한다
- 1단락 내 최소 2가지 문장 유형을 포함한다

### 피해야 할 표현
- **AI 나열형**: "첫째... 둘째... 셋째..." 남발 (2개까지만)
- **학술체 직역**: "실증 분석하였다", "통계적으로 유의하게"
- **과장**: "혁명적인", "획기적인", "패러다임 전환"
- **모호**: "~인 것 같다", "~일 수 있다"

## 패턴 4: 박스 & 콜아웃 요소

챕터당 2~4개 권장.

**A. 핵심 포인트 박스 (Key Takeaway)**
**B. 사례 심화 박스 (Deep Dive)**
**C. 주의사항 박스 (Warning)**
**D. 독자 질문 박스 (Reader Prompt)**
**E. 진단 항목 박스 (Validation Checkpoint)** — SAPD 도서 고유

```markdown
> **검증 항목 5.3**: 설명가능성 진단
> - [ ] 의사결정 함수 f의 입력 변수가 공개되어 있는가?
> - [ ] 변수별 가중치가 감사 가능한 상태인가?
> - [ ] 임계값 변경 시 결정이 어떻게 바뀌는지 추적 가능한가?
```

## 패턴 5: 챕터 클로징 구조

1. **핵심 요약** (3포인트 이하)
2. **실무 산출물 요약**: 이 장에서 도출한 체크리스트/매트릭스 정리
3. **다음 챕터 예고**: 자연스러운 연결

## 패턴 6: 그림 & 표 캡션 (한국어 형식)

```
그림 N-N. 제목 (출처: 저자명/기관명, 연도)
표 N-N. 제목
```

## 패턴 7: 인용 & 출처 표기 (도서 방식)

### 본문 내 인용
```
EU AI Act(2024)는 고위험 AI 시스템에 대해 설명가능성 의무를 부과하고 있다.
OECD(2019)는 AI 원칙에서 투명성과 책임성을 핵심 가치로 제시하였다.
```

## 패턴 8: 서문 & 후기 구조

### 서문 (4~6페이지)
1. **탄생 계기**: SAPD Framework 구상부터 도서화까지
2. **독자 약속**: 이 책을 읽고 나면 무엇을 할 수 있는가
3. **책의 구조**: 4부 12장의 연결 구조 안내
4. **감사 인사**

## 패턴 9: 피해야 할 도서 전체 표현

| 유형 | 피할 표현 | 대안 |
|------|---------|------|
| 논문체 | "본 연구에서는" | "이 책에서는" |
| 모호 | "이러한 다양한 요인들" | 요인을 직접 나열 |
| 과장 | "완벽한 해결책" | "효과적인 접근법" |
| 수동태 남발 | "~이 제안되었다" | "전문가들은 ~을 제안한다" |
| AI 나열 | "다음과 같은 장점이 있다: 1)..." | 서술형으로 통합 |
