# Data Patterns - 도서 자료 수집 & 정리 패턴

> Phase 2(조사 & 근거)에서 재사용. 사례 카드, 통계 검증, 자료 매핑 전용.

---

## 패턴 1: 사례 카드 표준 형식

```markdown
## 사례 카드 #NNN

**제목**: [사례 이름]
**주체**: [기관명 / 국가명]
**시기**: [연도 또는 기간]
**배경**: [2~3문장: 어떤 상황에서 일어난 일인가]
**핵심 포인트**: [핵심 교훈 1~2문장]
**수치**: [관련 수치 및 출처]
**출처**: [원문 링크 또는 서지 정보]
**사용 챕터**: [Ch.X, Ch.Y]
**SAPD 연결**: [관련 레이어 또는 검증 차원]
**태그**: [키워드 2~5개]
```

---

## 패턴 2: 통계 수치 검증 체크리스트

```markdown
### 수치: [수치 내용]

- [ ] 출처 원문(URL 또는 보고서명) 확인
- [ ] 발행 연도 확인 → 3년 이내: ✅ / 3~10년: ⚠️ / 10년 이상: ❌
- [ ] 출처 기관 신뢰성 → 정부기관/학술기관/국제기구: ✅ / 블로그/언론 단독: ⚠️
- [ ] 본문에 출처 명기 형식 확인 (기관명, 연도)

**검증 결과**: [ ] 사용 가능 / [ ] 조건부 사용 / [ ] 대체 필요
```

## 패턴 3: 통계 은행 표준 형식

```markdown
| # | 수치 내용 | 출처 | 연도 | 신뢰도 | 사용 챕터 |

| S-001 | EU AI Act 고위험 분류 AI 시스템 비율 | EU 집행위원회 | 2024 | ✅ | Ch.5, Ch.10 |
```

## 패턴 4: 경쟁 도서 분석 템플릿

```markdown
| 항목 | 경쟁 도서 A | 경쟁 도서 B | 우리 책 |
|------|-----------|-----------|---------|
| 제목 | | | 공공 AI 의사결정의 설계와 검증 |
| 핵심 주장 | | | SAPD + Validation Module |
| 강점 | | | |
| 약점 / 다루지 않는 것 | | | |
| 차별화 포인트 | | | ← 우리만의 공백 |

### 시장 공백 분석
경쟁 도서들이 공통적으로 다루지 않는 영역:
- 공백 1:
- 공백 2:
```
