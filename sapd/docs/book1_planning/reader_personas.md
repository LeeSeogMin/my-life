# 독자 페르소나

## Primary 독자 (주 독자층)

### 페르소나 1: 공공기관 AI 도입 담당자 — "김과장"

| 항목 | 내용 |
|------|------|
| 직업 | 중앙부처 디지털혁신팀 사무관 (행정고시 출신) |
| 연령대 | 30대 후반~40대 초반 |
| 배경 | 행정학/정책학 전공, 코딩 경험 없음, 데이터 분석은 보고서 수준 |
| 현재 고민 | AI 시스템 도입 예산이 배정됐는데, 사업자 제안서의 기술 용어를 평가할 기준이 없다. "AI가 편향되면 어쩌지?"라는 막연한 우려는 있으나 구체적 검토 방법을 모른다. |
| 기대하는 것 | 기술을 직접 구현하지 않아도, **도입 전 무엇을 점검해야 하는지** 체크리스트가 필요하다. 보고서에 첨부할 수 있는 검토 기준표. |
| 읽는 장 | 제4장(오류 유형), 제9장(Validation Checklist), 제10장(거버넌스), 제12장(조달) |

### 페르소나 2: 정책연구자 — "박연구원"

| 항목 | 내용 |
|------|------|
| 직업 | 국책연구원(KDI, KIPA 등) 부연구위원 |
| 연령대 | 30대 중반~40대 |
| 배경 | 정책학/경제학 박사, 정량 분석(회귀분석, DID) 가능, Python 기초 수준 |
| 현재 고민 | LLM을 정책분석 보조 도구로 활용하기 시작했으나, AI 출력의 타당성을 검증할 체계가 없다. "GPT가 만든 정책 대안을 보고서에 그대로 쓸 수 있는가?" |
| 기대하는 것 | AI 기반 정책분석의 **타당성 검증 프레임워크**. 인과추론 관점에서의 AI 출력 검토 기준. 학술적으로 인용 가능한 체계. |
| 읽는 장 | 제1~2장(SAPD 이론), 제4장(오류 유형), 제6장(타당성), 제8장(루브릭) |

## Secondary 독자 (부 독자층)

### 페르소나 3: AI 거버넌스 대학원생 — "이대학원생"

| 항목 | 내용 |
|------|------|
| 직업 | 행정학/데이터사이언스 석·박사 과정 대학원생 |
| 연령대 | 20대 후반~30대 초반 |
| 배경 | Python/R 분석 가능, ML/DL 기초 이수, 논문 작성 경험 있음 |
| 현재 고민 | AI 윤리/거버넌스로 논문을 쓰려는데, 기존 문헌은 원칙론에 그치고 조작화(operationalization)가 부족하다. 연구 프레임워크가 필요하다. |
| 기대하는 것 | **SAPD라는 새로운 이론적 프레임워크**를 자신의 연구에 적용할 수 있는 개념 도구. Validation Module의 차원·지표를 연구 변수로 활용. |
| 읽는 장 | 제2장(설계 원리), 제5장(XAI 재정의), 제7장(공정성), 제9장(통합 아키텍처) |

### 페르소나 4: AI 서비스 실무자 — "최PM"

| 항목 | 내용 |
|------|------|
| 직업 | AI 솔루션 기업의 공공사업 PM |
| 연령대 | 30대 |
| 배경 | 컴퓨터공학 전공, 기술은 알지만 공공부문의 법·제도·조달 절차에 익숙하지 않음 |
| 현재 고민 | 공공기관 RFP에 "AI 윤리 준수", "설명가능성 확보"라고 적혀 있는데, 구체적으로 무엇을 구현해야 하는지 기준이 모호하다. |
| 기대하는 것 | 공공 AI의 **설명가능성·공정성·타당성 요건**이 구체적으로 무엇인지. RFP 대응 시 참조할 수 있는 기준 체계. |
| 읽는 장 | 제5장(XAI), 제7장(공정성), 제8장(루브릭), 제11장(책임 구조), 제12장(조달) |
