## 상세 목차

### 서문 (4~6쪽)

### 제1부 — 왜 적응형 정책인가: SAPD 이론 기초

**제1장. 증거 기반 정책의 구조적 한계** (25~30쪽)
- 1.1 EBP의 성취와 전제
- 1.2 사후 평가의 함정
- 1.3 분절적 피드백 루프
- 1.4 데이터 활용의 비연속성
- 1.5 구조적 진단의 종합

**제2장. 상태 기반 적응형 정책의 설계 원리** (30~35쪽)
- 2.1 핵심 전환 — 개입에서 제어 논리로
- 2.2 EBP와 SAPD의 구조적 비교
- 2.3 수리적 기초와 지적 계보
- 2.4 5대 레이어 아키텍처
- 2.5 분석 도구군의 구조적 배치
- 2.6 공공 가치의 아키텍처적 내재화

**제3장. 운영적 현실로서의 SAPD — 팔란티어 동형성 분석** (25~30쪽)
- 3.1 분석 목적과 방법
- 3.2 팔란티어 플랫폼 구조
- 3.3 순환 피드백 루프의 대응
- 3.4 5대 레이어와 기술 스택 매핑
- 3.5 AI 역할 정의의 수렴
- 3.6 차이점 — 공공 가치의 설계 제약
- 3.7 함의 — 이론과 구현의 상보성

### 제2부 — 공공 AI는 어디서 실패하는가: 검증의 필요성과 구조

- 4.1 왜 오류 유형 분류가 필요한가
- 4.2 사실적 오류 (Factual Error)
- 4.3 논리적 오류 (Logical Error)
- 4.4 맥락적 오류 (Contextual Error)
- 4.5 프레이밍 오류 (Framing Error)
- 4.6 오류 유형 간 상호작용
- 4.7 오류 유형별 진단 기준 도출

**제5장. 설명가능성(XAI)의 공공적 재정의** (35~40쪽)
- 5.1 XAI의 기술적 계보
- 5.2 공공 영역에서의 설명가능성 재정의
- 5.3 국제 기준 비교
- 5.4 한국 공공 AI의 설명가능성 현황

- **[산출물]** XAI 진단 체크리스트

**제6장. 정책분석 타당성 검증 체계** (35~40쪽)
- 6.1 정책분석에서의 타당성 개념
- 6.2 AI 기반 분석의 타당성 위협
- 6.3 분석 질문의 구조적 검토
- 6.4 근거 추적과 출처 검증
- 6.5 타당성 검증 프레임워크
- 6.6 SAPD 루프에서의 타당성 확보
